## 🚀 Em destaque

### 🧓 Elder Web

[![Site no ar](https://img.shields.io/badge/Site_no_ar-elder--web.vercel.app-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://elder-web.vercel.app)
[![Repositório](https://img.shields.io/badge/Reposit%C3%B3rio-Elder__Web-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/MixuriM/Elder_Web)

Aplicação web de gestão de cuidados de idosos que reúne três perfis (idoso, cuidador e familiar) com permissões por vínculo. É o meu TCC na Etec, em uma equipe de 3 que eu lidero. Fiz o backend, o banco e a infraestrutura, e contribuí também no frontend. Integro e reviso os PRs do time.

- **API:** Node.js, Express e TypeScript, com Prisma, SQL Server e login por Firebase Auth (e-mail e Google)
- **Segurança:** autorização por vínculo validada no servidor, limite de taxa, CSP e HSTS, consentimento LGPD
- **Qualidade:** CI no GitHub Actions com `npm audit` e mais de 4 mil testes (Jest, Testing Library, Playwright e axe para acessibilidade)
- **Deploy:** Vercel (frontend), Render com Docker (backend) e Azure SQL (banco)

> O backend roda no plano gratuito do Render, então o primeiro acesso pode levar alguns segundos.

### 🐧 Nexus OS

[![Repositório](https://img.shields.io/badge/Reposit%C3%B3rio-nexus--os-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/MixuriM/nexus-os)

<img src="https://raw.githubusercontent.com/MixuriM/nexus-os/main/assets/logo-nexus-os.png" alt="Logo do Nexus OS" width="110" align="right">

Distro Linux para laboratórios de redes definidas por software (SDN) e virtualização de funções de rede (NFV), uma remasterização do Debian 13 com live-build. É o Projeto Integrador da Uniso, em uma equipe de 6 que eu lidero. Integro e reviso os PRs do time. Em andamento (RC1 mais desktop).

- **Na ISO:** Open vSwitch, KVM/QEMU com libvirt, Docker, FRRouting, Containerlab e desktop XFCE
- **Automação:** scripts de orquestração em Bash e 8 smoke tests que rodam dentro da ISO no QEMU
- **Licença:** GPL-3.0
